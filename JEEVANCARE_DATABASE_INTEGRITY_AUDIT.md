# JeevanCare — Database Integrity & Concurrency Audit Report

**Audit Date:** November 2026
**Scope:** MongoDB Indexing, Unique Constraints, Race-Condition Protection, Concurrency Guards, Data Types, and Schema Integrity.

---

## 1. Index Strategy & Concurrency Protection

JeevanCare enforces multi-tenant database integrity through Payload CMS field indexes and Mongoose native index initializers in `src/payload.config.ts`.

---

## 2. Key Database Index Matrix

| Collection | Index Name | Index Keys | Type / Constraint | Purpose |
| :--- | :--- | :--- | :--- | :--- |
| **`appointments`** | `uniq_active_slot` | `{ tenant: 1, doctor: 1, start: 1 }` | **Partial Unique** (`status: { $in: ['scheduled', 'checked-in'] }`) | Prevents double-booking a doctor's active time slot concurrently. |
| **`appointments`** | `uniq_walkin_token_day` | `{ tenant: 1, tokenDay: 1, tokenNumber: 1 }` | **Partial Unique** (`tokenNumber: { $exists: true }`) | Ensures daily OPD token uniqueness (`T-01`, `T-02`) per clinic. |
| **`users`** | `uniq_patient_profile_portal` | `{ patientProfile: 1 }` | **Partial Unique** (`role: 'patient'`) | Enforces 1-to-1 link between patient profile and portal user account. |
| **`invoices`** | `uniq_invoice_number` | `{ tenant: 1, invoiceNumber: 1 }` | **Unique** | Prevents duplicate invoice numbers within a clinic. |
| **`patients`** | `idx_tenant_mrn` | `{ tenant: 1, mrn: 1 }` | **Indexed** | Fast lookup for Medical Record Numbers. |

## 3. Concurrency & Integrity Vulnerability Audit

### Finding DBI-001 (P2): Concurrency Lock Status Scope
* **File:** `src/payload.config.ts` (`onInit` hook)
* **Finding:** The `uniq_active_slot` partial filter expression checks `status: { $in: ['scheduled', 'checked-in'] }`, but omits `'in-consultation'` and `'post-consultation'`.
* **Impact:** If an appointment is transitioned to `in-consultation`, a race condition during a concurrent booking could allow a second appointment to be inserted for that doctor at the same start time.
* **Remediation:** Expand partial filter expression in `onInit` to:
  `partialFilterExpression: { status: { $in: ['scheduled', 'checked-in', 'in-consultation', 'post-consultation'] } }`

---

### Finding DBI-002 (P2): Invoice Number Generator Sequential Race
* **File:** `src/collections/Invoices.ts` (Number Generator)
* **Finding:** Invoice numbers are generated by counting existing documents (`count + 1`).
* **Impact:** High-volume concurrent checkout requests at reception could generate matching `invoiceNumber` values simultaneously, hitting the unique index duplicate key error.
* **Remediation:** Use atomic counter documents (`findAndModify`) for clinic invoice number generation.
